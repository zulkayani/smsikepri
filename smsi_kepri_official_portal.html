Tentang SMSI Kepri

Serikat Media Siber Indonesia (SMSI) adalah salah satu konstituen resmi Dewan Pers yang menghimpun para pemilik, pengelola, dan penanggung jawab perusahaan media siber (online) di seluruh wilayah Republik Indonesia.

SMSI Provinsi Kepulauan Riau didirikan sebagai wadah komunikasi, koordinasi, dan advokasi bagi pengusaha media siber lokal agar dapat bertransformasi menjadi perusahaan pers yang sehat, profesional, patuh hukum pers, serta berkontribusi aktif dalam pembangunan daerah Kepulauan Riau.

Visi Organisasi

Terwujudnya ekosistem perusahaan media siber di Kepulauan Riau yang profesional, mandiri, berintegritas, dan mampu mengawal keberlanjutan pers nasional di era digital.

Misi Organisasi

  • Mendorong standarisasi perusahaan media siber sesuai ketentuan Dewan Pers dan UU No. 40 Tahun 1999 tentang Pers.
  • Meningkatkan kapasitas kompetensi wartawan dan pengelola media siber anggota.
  • Membangun sinergi strategis dengan pemerintah daerah, TNI/Polri, swasta, dan pemangku kepentingan.
  • Memberikan perlindungan serta advokasi hukum bagi usaha media anggota SMSI.

Skema Database MySQL (smsi_kepri) & Migration Laravel

Struktur tabel database relasional MySQL yang siap langsung di-migrate ke proyek Laravel backend.

CREATE DATABASE IF NOT EXISTS `smsi_kepri` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE `smsi_kepri`;

-- 1. Tabel Users (Admin & Editor Authentication)
CREATE TABLE `users` (
  `id` bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` varchar(255) NOT NULL,
  `email` varchar(255) NOT NULL UNIQUE,
  `password` varchar(255) NOT NULL,
  `role` enum('superadmin','admin','editor') NOT NULL DEFAULT 'editor',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. Tabel Media Anggota
CREATE TABLE `media` (
  `id` bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  `logo` varchar(255) DEFAULT NULL,
  `nama_perusahaan` varchar(255) NOT NULL,
  `nama_media` varchar(255) NOT NULL,
  `slug` varchar(255) NOT NULL UNIQUE,
  `website` varchar(255) NOT NULL,
  `direktur` varchar(255) NOT NULL,
  `pemimpin_redaksi` varchar(255) NOT NULL,
  `alamat` text NOT NULL,
  `kabupaten_kota` varchar(100) NOT NULL,
  `email` varchar(255) NOT NULL,
  `telepon` varchar(50) DEFAULT NULL,
  `tahun_bergabung` year(4) NOT NULL,
  `nomor_anggota` varchar(100) DEFAULT NULL,
  `status_keanggotaan` enum('Aktif','Pending','Nonaktif') NOT NULL DEFAULT 'Pending',
  `deskripsi` text DEFAULT NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 3. Tabel Kategori Berita
CREATE TABLE `kategori_berita` (
  `id` bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  `nama` varchar(100) NOT NULL,
  `slug` varchar(100) NOT NULL UNIQUE,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 4. Tabel Berita
CREATE TABLE `berita` (
  `id` bigint(20) UNSIGNED NOT NULL AUTO_INCREMENT,
  `judul` varchar(255) NOT NULL,
  `slug` varchar(255) NOT NULL UNIQUE,
  `kategori_id` bigint(20) UNSIGNED NOT NULL,
  `gambar` varchar(255) DEFAULT NULL,
  `ringkasan` text DEFAULT NULL,
  `isi` longtext NOT NULL,
  `penulis` varchar(100) NOT NULL,
  `status` enum('published','draft') DEFAULT 'published',
  `tanggal_publikasi` date NOT NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  FOREIGN KEY (`kategori_id`) REFERENCES `kategori_berita`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
